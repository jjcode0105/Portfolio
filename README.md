# 제이제이코드

> AI와 데이터 기술을 활용해, 현장의 반복 업무와 복잡한 운영 문제를 제품으로 해결합니다.

제이제이코드는 기획부터 설계, 개발, 배포와 운영 개선까지 함께하는 IT 솔루션 파트너입니다.
SaaS, 관리자 시스템, 이커머스·교육 플랫폼, 검색 데이터 분석과 업무 자동화 분야의 웹 서비스를 만듭니다.

## 제공하는 서비스

- B2B SaaS 및 내부 업무 시스템 구축
- 온라인 교육·커머스 플랫폼 개발
- 관리자 페이지, 권한 관리, 운영 대시보드 설계
- 검색·광고 데이터 분석 및 리포팅 자동화
- 결제, 수강권, 쿠폰, 환불 등 복잡한 비즈니스 로직 구현
- 기존 서비스 기능 고도화, 모바일 UX 개선, 배포·운영 안정화

## 대표 프로젝트

### ADVoost — 검색·광고 분석 자동화 SaaS

웹사이트 URL을 분석해 검색·광고 적합도를 진단하고, 개선 방향을 제안하는 B2B SaaS입니다.

| 구분 | 내용 |
| --- | --- |
| 해결한 문제 | 반복적인 URL 진단, 결과 정리, 대행사별 운영 업무를 하나의 서비스로 통합 |
| 주요 기능 | 단일·다중 URL 분석, 분석 이력, 관리 URL, 개선 세션, PDF 보고서, 크레딧, 대행사·회원 관리 |
| 운영 기능 | 역할 기반 권한, 관리자 통계·모니터링, 가이드와 분석 규칙 관리 |
| 기술 | Next.js, React, TypeScript, Supabase, PostgreSQL, Tailwind CSS, Vercel |

**핵심 역량**: 데이터 기반 진단 자동화, 다단계 권한 설계, SaaS 운영 기능, 리포팅과 과금 흐름

강의 판매부터 결제, 수강, 콘텐츠 운영, 환불까지 연결한 온라인 교육 서비스입니다.

| 구분 | 내용 |
| --- | --- |
| 해결한 문제 | 교육 상품 판매와 수강 운영, 고객 지원 업무가 분리되어 생기는 운영 복잡도 해소 |
| 주요 기능 | 회원·상품·강의 관리, 장바구니·주문·결제, 수강권, 강의 시청, 게시판, 쿠폰·포인트·환불 |
| 운영 기능 | 강의·영상·주문·회원 관리 어드민, 수강 만료 제어, 모바일 강의실 UX 개선 |
| 기술 | Next.js, React, TypeScript, Supabase, PostgreSQL, Prisma, PortOne, Zoom SDK, Vercel |

**핵심 역량**: 서비스·관리자·DB를 분리한 멀티 저장소 구조, 커머스 도메인 설계, 접근 제어, 운영 중인 제품의 지속적 개선

| 구분 | 내용 |
| --- | --- |
| 해결한 문제 | 매출, 비용, 외주 정산, 증빙, 세무 일정을 여러 문서로 관리하는 비효율 해소 |
| 주요 기능 | 거래처·프로젝트, 매출·입금, 비용·증빙, 외주 정산, 세무 일정, 대시보드·리포트 |
| 구현 범위 | 데이터 모델, 화면·API 명세, Docker 기반 인프라 설계부터 실제 기능 구현까지 연결 |
| 기술 | Next.js, React, TypeScript, Prisma, S3 호환 저장소, Zod/OpenAPI, Docker |

**핵심 역량**: 복잡한 현업 업무를 제품 요구사항과 데이터 모델로 구조화, 사내 시스템 설계·구축

| 구분 | 내용 |
| --- | --- |
| 해결한 문제 | 검색 성과 데이터를 정기적으로 수집하고, 프로젝트별 변화 추이를 쉽게 확인할 수 있도록 시각화 |
| 주요 기능 | 프로젝트·그룹·태그·키워드 관리, 순위·가시성·트래픽 데이터, 대시보드, 배치 적재 |
| 비즈니스 기능 | 사용자 인증, 결제·구독 관리 |
| 기술 | Next.js, TypeScript, Supabase Auth, Prisma, Vercel |

**핵심 역량**: 검색 데이터 파이프라인, 대시보드, 구독형 SaaS 구조

## 협업 방식

1. 문제와 운영 흐름을 먼저 정리합니다.
2. 화면, 데이터, 권한, 예외 상황을 함께 설계합니다.
3. 기능 단위로 빠르게 구현하고 실제 사용 흐름에서 검증합니다.
4. 배포 이후에도 운영 데이터와 사용자 피드백을 바탕으로 개선합니다.

## 프로젝트 문의

SaaS, 관리자 시스템, 교육·커머스 플랫폼, 데이터 분석·업무 자동화 프로젝트를 논의할 수 있습니다.
프로젝트 성격과 공개 범위에 따라 상세 사례, 화면, 아키텍처 자료를 별도로 공유합니다.
